PALABRÓN — INSTALLABLE WEB APP

This is a Progressive Web App (PWA) based on the playable first-week prototype.

PUBLISHING (HTTPS REQUIRED):
1. Unzip this package.
2. Upload the CONTENTS of the palabron_app folder to a static hosting provider such as Netlify, Cloudflare Pages, Vercel, or GitHub Pages.
3. Open the HTTPS link from an iPhone in Safari.
4. Tap Share > Add to Home Screen.
5. Android Chrome: open the HTTPS link and choose Install app / Add to Home Screen.

For local desktop testing, in the extracted folder run: python3 -m http.server 8000
Then open http://localhost:8000 . A file:// opening will NOT register service workers.

IMPORTANT: This is an installable web app, not an Apple App Store or Google Play native binary. Offline play is available after loading once online. Progress is local to the browser/device. Daily challenges remain the 7 unlocked demo days (not automatically rotating). The answer bank and scores remain illustrative and limited.
